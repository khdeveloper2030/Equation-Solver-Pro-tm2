Quadratic

រូបមន្តសមីការដឺក្រេទី ២

ax² + bx + c = 0   (a ≠ 0)
  • ឌីស្គ្រីមីណង់ (Discriminant): Δ = b² - 4ac
  • ករណី Δ > 0 (ឫសពិត ២ ផ្សេងគ្នា): x₁ = (-b + √Δ) / 2a ,   x₂ = (-b - √Δ) / 2a
  • ករណី Δ = 0 (ឫសឌុប): x₁ = x₂ = -b / 2a
  • ករណី Δ < 0 (ឫសកុំផ្លិចឆ្លាស់): x = (-b ± i√|Δ|) / 2a
  • ទំនាក់ទំនង Viète: S = x₁ + x₂ = -b/a ,   P = x₁·x₂ = c/a
Cubic

រូបមន្តសមីការដឺក្រេទី ៣ (Cardano)

ax³ + bx² + cx + d = 0   (a ≠ 0)
  • បម្លែងជាទម្រង់សង្ខេប (x = t - b/3a): t³ + pt + q = 0
  • មេគុណ p និង q: p = (3ac - b²) / 3a² ,   q = (2b³ - 9abc + 27a²d) / 27a³
  • ឌីស្គ្រីមីណង់ដឺក្រេទី ៣: Δ₀ = (q/2)² + (p/3)³
  • រូបមន្ត Cardano (Δ₀ > 0): t = ∛(-q/2 + √Δ₀) + ∛(-q/2 - √Δ₀)
  • ទំនាក់ទំនង Viète ដឺក្រេទី ៣: x₁+x₂+x₃ = -b/a ,   x₁x₂x₃ = -d/a
